# PWA Teknisi: Alur dan Spesifikasi Layar L1

Rujukan: 01 L1-T01..T11, bagian 8.2; 02 FR-050..060, FR-063. Navigasi bawah: Tugas Hari Ini, Semua Tugas, Sinkron, Profil.
Semua aksi tulis masuk antrean lokal (WP-109) dan dikirim lewat `/sync/push`. Layar tidak pernah mengubah status langsung.

| ID     | Layar                          | Isi                                                                                                                                          | Aksi utama                  | Keadaan khusus                                                                                                                                       |
| ------ | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| -      | Masuk                          | Email, kata sandi                                                                                                                            | **Masuk**                   | Setelah masuk, tugas disimpan untuk offline                                                                                                          |
| L1-T01 | Tugas Hari Ini                 | Kartu urut: jam, pelanggan, alamat singkat, jenis layanan, status, `SyncIndicator` per item                                                  | Buka tugas                  | Kosong: "Tidak ada tugas hari ini". Tidak ada harga di mana pun                                                                                      |
| -      | Semua Tugas                    | Daftar dengan filter status                                                                                                                  | Buka tugas                  | Dari cache bila offline                                                                                                                              |
| L1-T02 | Detail WO                      | Pelanggan, kontak (tombol telepon), alamat + tombol buka peta, aset, riwayat singkat aset, catatan penugasan                                 | Sesuai status               |                                                                                                                                                      |
| L1-T03 | Terima / Tolak / Minta bantuan | Tiga tombol; Tolak wajib memilih alasan (pilihan + teks opsional)                                                                            | **Terima**                  | Menolak mengembalikan ke dispatcher                                                                                                                  |
| -      | Berangkat                      | -                                                                                                                                            | **Berangkat**               | Opsional bila langsung check-in                                                                                                                      |
| L1-T04 | Check-in / Check-out           | Izin lokasi diminta saat dipakai                                                                                                             | **Check-in**, **Check-out** | Izin ditolak: pilih "Tanpa lokasi" + alasan wajib (K-14, FR-053). Waktu dicatat di perangkat dan dikirim bersama                                     |
| L1-T05 | Checklist                      | Item satu per satu, tombol besar Ya / Tidak / Tidak berlaku; catatan diagnosa                                                                | **Berikutnya**              | Item wajib ditandai. Tersimpan lokal per item                                                                                                        |
| L1-T06 | Foto sebelum/sesudah           | Kamera langsung; pratinjau; hapus sebelum kirim                                                                                              | **Ambil Foto**              | Dikompres di perangkat (K-09). Status unggah per foto; tidak bisa dihapus setelah tersinkron (API-AS-06)                                             |
| L1-T09 | Tanda tangan pelanggan         | Kanvas layar penuh, nama penandatangan                                                                                                       | **Simpan Tanda Tangan**     | Bukti penerimaan internal, bukan tanda tangan bersertifikat (non-goal 3.4)                                                                           |
| L1-T10 | Tutup WO                       | Ringkasan. Bila belum bisa ditutup: **seluruh kekurangan sekaligus** (checklist, foto, tanda tangan) dengan tautan ke layar terkait (BR-040) | **Tutup Pekerjaan**         | Status berubah setelah ACK server                                                                                                                    |
| L1-T08 | Sinkron                        | Status global; antrean per item (belum terkirim, mengirim, terkirim, gagal + penyebab); sisa penyimpanan                                     | **Coba Kirim Lagi**         | `APP_UPDATE_REQUIRED`: banner "Perbarui aplikasi", antrean tidak dihapus. Data untuk WO yang dibatalkan atau dialihkan tampil sebagai "Diselamatkan" |
| -      | Profil                         | Nama, perangkat, versi                                                                                                                       | **Keluar**                  | Keluar dengan antrean belum terkirim: peringatan keras, tidak menghapus diam-diam                                                                    |

Teks indikator sinkron tetap: "Belum terkirim", "Mengirim...", "Terkirim", "Gagal, akan dicoba lagi". Header menampilkan jumlah item belum terkirim dan status jaringan.

Uji nyata di perangkat (mode pesawat, kamera, GPS, kanvas) dilakukan manusia di WP-117.
