# Daftar Teks UI (Bahasa Indonesia, L1)

Aturan: kalimat pendek, kata kerja di awal tombol, tanpa istilah internal. Pesan galat menyebut apa yang terjadi dan langkah berikutnya.

## Status pelanggan (02 bagian 4.2)

| Kunci        | Teks                      |
| ------------ | ------------------------- |
| received     | Diterima                  |
| scheduled    | Dijadwalkan               |
| en_route     | Teknisi menuju lokasi     |
| in_progress  | Sedang dikerjakan         |
| awaiting_you | Menunggu persetujuan Anda |
| done         | Selesai                   |
| cancelled    | Dibatalkan                |
| rejected     | Tidak dapat diproses      |

## Sinkron (FR-060)

| Kunci           | Teks                                                     |
| --------------- | -------------------------------------------------------- |
| pending         | Belum terkirim                                           |
| sending         | Mengirim...                                              |
| synced          | Terkirim                                                 |
| failed          | Gagal, akan dicoba lagi                                  |
| offline         | Anda sedang offline. Pekerjaan tetap tersimpan di ponsel |
| update_required | Perbarui aplikasi. Data Anda tidak hilang                |

## Galat umum

| Situasi            | Teks                                                       |
| ------------------ | ---------------------------------------------------------- |
| Jaringan hilang    | Tidak ada sinyal. Data disimpan dan dikirim otomatis nanti |
| Batas laju         | Terlalu banyak percobaan. Coba lagi beberapa saat lagi     |
| Tidak berhak       | Anda tidak punya akses ke halaman ini                      |
| Tidak ditemukan    | Data tidak ditemukan                                       |
| Konflik versi      | Data sudah berubah. Ini tampilan terbaru                   |
| Tidak bisa ditutup | Pekerjaan belum bisa ditutup. Lengkapi hal berikut:        |

## Tombol utama

Masuk, Daftar, Kirim Pesanan, Pesan Servis, Terima, Tolak, Berangkat, Check-in, Check-out, Ambil Foto, Simpan Tanda Tangan, Tutup Pekerjaan, Coba Kirim Lagi, Keluar, Batalkan.

Teks khusus kontrak, SLA, dan biaya ada di Lapis 2.
